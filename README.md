# Group-Level-Driving-Force
A repository containing the code and data to reproduce the results in the manuscript titled "**A group-level driving force dominates collective movement decision-making**"

### Description
Below is a short description of what each file and folder contains:
* *Figures*: Folder containing MATLAB code to reproduce figures in the manuscript, sorted by the figure numbers
* *SI Figures*: Folder containing MATLAB code to reproduce figures in the SI appendix, sorted by the figure numbers

MATLAB code starting with `homogeneous.m`,`powerlaw.m`,`two_component.m`, and `uniform.m` runs simulations and analyses, which represent our four group types in this work.

* *models*: Folder containing MATLAB code to simply achieve a visualization for the model. This is exemplified by the typical two-component group composed of informed individuals and uninformed individuals. 

Within each subdirectory, there may be a folder named "data" which contains pre-computed outputs for computations that may take a long time to complete. The outputs can also be regenerated by changing the **SAVE** flag, which will re-run everything.
